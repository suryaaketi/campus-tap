    One tag. One starting point.

    Copy the link for where you will place a tag. Write it as a URL / URI using the free NFC Tools app, then tap the tag with your phone.

    1. Copy a location linkEach link gives the map its starting point.
    2. Write it to your NFC tagNFC Tools: Write, Add a record, URL / URI, then Write.
    3. Tap, choose, walkOpen the notification and choose a destination.

    Keep prototype tags writable. A tag fixes your starting point; it does not track your movement. Phone location is optional and is not saved by this demo.
