Map data & sources

A student prototype for Penn State University Park and downtown State College.

OpenStreetMap

Map and walking network © OpenStreetMap contributors. The derived walking database is available under the Open Database License 1.0. Path data was retrieved on October 29, 2026. Download the derived walking graph or view the mapped starting points and their OSM source links.

Campus Tap calculates routes in your browser using this local outdoor path network. Estimates use a walking pace of 75 meters per minute. Road segments receive a preference penalty so the router favors mapped paths when practical. The displayed distance uses physical path lengths, without that penalty.

“Avoid mapped stairs” excludes paths marked as steps in this data. It is not a guarantee of wheelchair accessibility. Building access, opening hours, construction closures, lighting and surface conditions have not been verified. Follow actual signs, crossings and local conditions.

Map display and optional directions

Leaflet 1.9.4 provides the interactive map under its BSD 2-Clause license. The background map uses a bundled vector extract of OpenStreetMap buildings, parks, streets and paths. It does not request any external map tiles. This extract is also a derived database under ODbL 1.0: download the background map data.

The optional Google Maps button uses Google Maps URLs, without a paid Maps API integration. Opening that button sends the route endpoints to Google Maps.

Phone location and NFC

The demo requests phone location only when you press “Use my location.” It does not save GPS coordinates, run background tracking or include location analytics. Routes are computed locally. The NFC tag stores a URL with a starting point such as ?start=hub. It does not contain the website code or track the person scanning it.

Campus Tap is an independent student prototype, not an official Penn State navigation service.
